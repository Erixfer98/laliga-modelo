## Pulso expandido en móvil

La vista inicial muestra cinco equipos. El botón permite consultar la lista completa, conservando el filtro seleccionado. En escritorio la lista completa permanece visible.

- [Lista expandida · claro](despues-inicio-expandido-390-light.png)
- [Lista expandida · oscuro](despues-inicio-expandido-390-dark.png)

Las capturas «después» de Inicio, Análisis y Boleto se actualizan con los ajustes finales de texto, historial por equipo y singular/plural.
